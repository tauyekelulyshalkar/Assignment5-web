# Assignment 5 — JavaScript Basics
A responsive, vanilla-JavaScript implementation of the three tasks in Assignment #5.

## Chosen options
- **Task 1:** Code Breaker — four unique digits, eight attempts, feedback for exact/misplaced digits, restart without page reload.
- **Task 2:** Kanban Board — 10 data objects, three columns, tag filter, priority sorting, progress calculation with a loop, delegated card controls, and a three-card In progress limit.
- **Task 3:** Character Creator — live preview, six validated fields, exactly 20 skill points, class-specific minimum skill, reserved-name check, inline errors and accessible error summary.

## Run locally
Open `index.html` in a modern browser. No build tools or libraries are needed.

## Files
- `index.html` — page structure
- `styles.css` — responsive styles and visual states
- `js/task1.js` — game logic
- `js/task2.js` — array-driven Kanban board
- `js/task3.js` — form validation and preview
- `screenshots/` — report screenshots
